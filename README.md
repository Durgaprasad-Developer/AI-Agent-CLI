- **File Management**: Create and read files directly from instructions.
- **Terminal Integration**: Execute shell commands as part of the reasoning process.
- **External APIs**: Built-in tools for live weather data and GitHub user profiles.

## 🚀 Getting Started

1. **Clone & Setup**:
   ```bash
   git clone https://github.com/Durgaprasad-Developer/AI-Agent-CLI.git
   cd AI-Agent-CLI
   ```

2. **API Key**:
   Create a `.env` file and add your Gemini API Key:
   ```bash
   GEMINI_API_KEY=your_key_here
   ```

3. **Run the Agent**:
   ```bash
   node index.js
   ```
